## 1. 개요

### 1.1 배경
Billage 프로젝트는 초기 개발 단계에서 빠른 개발을 위해 대부분의 포트를 `0.0.0.0/0`으로 열어둔 상태였습니다. 서비스 안정화 이후 보안 강화 작업을 진행하여 Zero Trust 원칙에 기반한 접근 제어를 구현했습니다.

### 1.2 목표
- 공격 표면(Attack Surface) 최소화
- 역할 기반 접근 제어(RBAC) 구현
- 중앙 집중식 모니터링 체계 구축
- 인프라 코드화(IaC)를 통한 보안 정책 관리

## 4. WireGuard VPN 구축

### 4.1 아키텍처

```
┌─────────────────────────────────────────────────────────────────┐
│                      WireGuard VPN 구성                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  VPN Server: Management VPC Public Subnet (10.2.1.x)            │
│  VPN Tunnel: 10.100.0.0/24                                      │
│  UDP Port: 51820                                                │
│                                                                  │
│  역할별 IP 할당:                                                 │
│  ├─ 10.100.0.1        → VPN Server                              │
│  ├─ 10.100.0.16/28    → DEVOPS (17-30): Full Access            │
│  ├─ 10.100.0.32/28    → BACKEND (33-46): SSH, MySQL, Spring    │
│  ├─ 10.100.0.48/28    → FRONTEND (49-62): Web Ports            │
│  └─ 10.100.0.64/28    → AIML (65-78): FastAPI, SSH             │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 역할별 접근 권한

| 역할 | IP 대역 | SSH | MySQL | Spring | Next.js | FastAPI | Grafana |
|------|---------|:---:|:-----:|:------:|:-------:|:-------:|:-------:|
| DEVOPS | 10.100.0.17-30 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| BACKEND | 10.100.0.33-46 | ✅ | ✅ | ✅ | ❌ | ❌ | ❌ |
| FRONTEND | 10.100.0.49-62 | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ |
| AIML | 10.100.0.65-78 | ✅ | ❌ | ❌ | ❌ | ✅ | ❌ |

### 4.3 VPC Peering + NAT 구성

VPN 클라이언트가 Dev/Prod VPC에 접근하기 위해 VPC Peering과 Masquerade(SNAT)를 조합:

```bash
# VPN 서버 PostUp 규칙
iptables -t nat -A POSTROUTING -s 10.100.0.0/24 -o eth0 -j MASQUERADE
```

## 6. 탐지된 공격 시도

프로덕션 환경에서 실제로 탐지된 공격 패턴:

### 6.1 Git Repository 탈취 시도
```log
216.81.245.109 - "GET /.git/config HTTP/1.1" 404
```
**대응**: `.git` 경로 Nginx에서 차단

### 6.2 ThinkPHP RCE 공격 (CVE-2018-20062)
```log
98.88.247.68 - "GET /?s=/Index/\think\app/invokefunction..." 200
```
**대응**: PHP 미사용으로 영향 없음

### 6.3 Spring Boot Actuator 스캔
```log
98.88.247.68 - "GET /actuator/env HTTP/1.1" 404
```
**대응**: Actuator 외부 노출 차단, VPN 경유만 허용

## 9. 결론

Billage 프로젝트는 WireGuard VPN 기반의 역할별 접근 제어와 Security Group 강화를 통해 Zero Trust 보안 모델을 구현했습니다. 모든 관리 접근은 VPN을 경유하며, 일반 사용자는 Nginx 리버스 프록시를 통해서만 서비스에 접근할 수 있습니다.

### 핵심 성과
1. **공격 표면 99% 감소**: SSH, DB, 백엔드 포트 외부 노출 제거
2. **역할 기반 접근 제어**: 팀별 최소 권한 원칙 적용
3. **중앙 집중 모니터링**: Prometheus/Grafana/Loki 통합
4. **인프라 코드화**: Terraform으로 보안 정책 버전 관리
