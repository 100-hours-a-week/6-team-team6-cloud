# 📡 NFC Lab — 상상 코딩 프로젝트

> 안드로이드 스튜디오 없이, 대화로 설계하고 md로 관리하는 NFC 안드로이드 앱 개발 프로젝트.
> 목표: 나중에 스튜디오 깔면 **그대로 복붙해서 돌아가는** 수준의 코드와 문서를 만든다.

## 프로젝트 목표

1. NFC 통신 프로토콜을 제대로 이해한다 (ISO 14443, NDEF, APDU)
2. 안드로이드 NFC API로 실제 동작하는 앱을 설계·구현한다
3. 모든 산출물은 md 파일로 버전 관리한다

## 폴더 구조

```
nfc-lab/
├── README.md                     ← 지금 이 파일 (프로젝트 현황판)
├── docs/
│   └── 01-nfc-protocol-basics.md ← NFC 프로토콜 기초 이론
└── app/                          ← 앱 코드 (md 안에 코드블록으로 관리)
```

## 진행 상황

| 단계 | 내용 | 상태 |
|------|------|------|
| 0 | 프로젝트 셋업, NFC 기초 이론 정리 | ✅ 완료 |
| 1 | 앱 컨셉 결정 → **TapNote** (폰↔폰 쪽지, HCE+리더) + APDU 프로토콜 v1 설계 | ✅ 완료 |
| 2 | 프로젝트 구조 + Manifest + HCE 서비스 등록 | ✅ 완료 |
| 3 | `ApduProtocol.kt` — 공용 프로토콜 코드 | 🔜 다음 |
| 4 | `TapNoteCardService.kt` — 카드 역할 (보내기) | ⬜ |
| 5 | `TapNoteReader.kt` + `MainActivity.kt` — 리더 역할 + UI | ⬜ |
| 6 | 상상 테스트 (시나리오 검증) | ⬜ |

## 개발 규칙

- 코드는 md 코드블록으로 작성하되, 파일 경로를 명시해서 나중에 그대로 옮길 수 있게 한다
- 매 단계마다 "이 코드가 폰에서 실행되면 무슨 일이 일어나는지" 시나리오로 검증한다
- 언어: Kotlin, 최소 SDK: API 26 (Android 8.0)
